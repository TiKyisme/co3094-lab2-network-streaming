## HTTP TASK

- Không sửa mã nguồn chính thức của giảng viên.

- Hướng dẫn chạy server trên Ubuntu VM.
- Hướng dẫn Windows truy cập trang bằng địa chỉ IP thực tế.
- Kiểm tra HTTP response và chức năng button.
- Chuẩn bị screenshot browser thật cho Form.

## DNS TASK

- Tạo một DNS Server dùng UDP bằng Python socket, ưu tiên thư viện chuẩn, không thêm dependency không cần thiết.
- Server phải phân tích được truy vấn DNS A record cho `www.example.com`.
- Trả về DNS response hợp lệ, có transaction ID tương ứng và resource record đúng cấu trúc.
- Cấu hình một IP trả lời phục vụ minh họa, ghi rõ giá trị và không giả vờ đó là địa chỉ thực của example.com nếu chưa xác minh.
- Hướng dẫn bind UDP port 53 trên Ubuntu và giải quyết quyền bind nếu cần.
- Hướng dẫn chạy `nslookup www.example.com <VM_IP>` từ Windows.
- Kiểm tra có output thật từ DNS Server trước khi xác nhận thành công.
- Chuẩn bị screenshot terminal hiển thị lệnh, DNS Server được truy vấn và kết quả.
