# Tin nhắn gửi nhóm

Mọi người ơi, mình đã chuẩn bị xong bộ tài liệu Lab 2 để cả nhóm bắt đầu. Lab có hai phần chính: demo máy Windows thật truy cập HTTP server trên Ubuntu VM, và chuẩn bị ba bản thiết kế nháp cho Reliability, Flow Control, Congestion Control. Phần thiết kế hiện là đề xuất để mình cùng review, chưa phải yêu cầu phải code hoàn chỉnh.

Mình đề xuất chia ba cặp, mỗi cặp phụ trách một cơ chế. Cặp Reliability đang giữ tạm tên Gia Đạo và Thiên Kỳ theo tài liệu cũ, nhưng vẫn cần hai bạn xác nhận. Bốn vị trí Flow Control và Congestion Control để trống chờ mọi người nhận. HTTP demo cũng cần một bạn chính và một bạn backup/reviewer; hiện chưa phân công.
